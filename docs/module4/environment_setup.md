# Настройка среды разработки

## IDE
Выбран Visual Studio Code (VS Code).

## Установленные расширения
- Python (Microsoft) — поддержка Python
- Black Formatter — автоформатирование Python
- Flake8 — линтинг Python
- EditorConfig — единые отступы
- Prettier — форматирование JS/CSS/HTML

## Горячие клавиши
- Форматирование документа: `Shift + Alt + F`
- Открыть терминал: `Ctrl + ~`
