# BookingForStudents

Краткое описание назначения:
Система предназначена для организации записи студентов на мероприятия, консультации и семинары, проводимые преподавателями. Преподаватель создаёт слоты с указанием темы, даты, времени, места и количества участников, а студенты просматривают доступные слоты и записываются на них. Система решает проблему хаотичной записи через чаты и устные договорённости, обеспечивая прозрачное расписание и автоматический учёт записавшихся
